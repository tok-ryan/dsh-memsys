# 任务：为记忆系统评测出 20 道口语化题

## 输入

- 记忆库：`eval/memories-export.md`（25 条，每条有 id / 类型 / 日期 / 原文 / 为什么记）

## 产出

写一个文件：`eval/questions-codex.json`，结构：

```json
{
  "generated_by": "codex",
  "count": 20,
  "questions": [
    {
      "id": "c01",
      "ask": "口语化的问句",
      "gold_memory_ids": ["mem_xxx"],
      "must": [{ "key": "标签", "variants": ["说法1", "说法2", "说法3"] }]
    }
  ]
}
```

## 规则

1. `ask` 必须像真人随口问助手：短、口语、含糊一点。**禁止照抄记忆原文措辞**，否则检索等于白送答案。
   - 好例子：「我挥霍 token 吗」「我最晚几点睡」「她叫什么来着」
   - 坏例子：「请描述主人的成本敏感度」「总结主人对音乐的偏好边界」
2. `gold_memory_ids`：1~3 条能回答这题的记忆 id，从文件里的 `id:` 字段完整复制。
3. `must`：2~3 个判分事实点，每个给 3~5 个同义 `variants`（覆盖不同说法，别把判分写太严）。
4. 20 题要尽量覆盖全部 25 条记忆（一题可引用多条）。
5. 其中 **3 道是陷阱题**：记忆里其实没有答案，正确反应是承认不确定。这类题 `gold_memory_ids` 为 `[]`，
   `must` 只有一条：`{ "key": "承认不确定", "variants": ["不确定", "不知道", "没有记录", "记忆里没有", "查不到"] }`。
6. 话题分布均衡，不要 20 题全在问偏好。

## 约束

- 只写 `eval/questions-codex.json` 这一个文件，不要改仓库其它文件。
- 不要执行 git 操作，不要安装依赖。

## 完成后只回复

1. 题量
2. 覆盖了多少条记忆（去重后）
3. 3 道陷阱题分别是哪几题（题号 + 一句话）

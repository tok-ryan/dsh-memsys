# persona/ · 人格版本目录

人格是宿主配置里唯一「只有主人能改」的文本。这里放**出厂种子**，运行时把主人改过的版本写到数据目录。

## 约定

- 文件名必须是 `v<数字>.md`（`v1.md`、`v2.md`、`v10.md`…）；其它文件（本 README）会被忽略。
- **当前版本 = 数字最大的那个**（按数字比较，v10 > v2），不是按修改时间。
- 写新版本时只新增文件，**绝不改写旧文件**——版本历史就是这个目录本身。
- 主人保存时，新版本落到 `<数据目录>/persona/v(max+1).md`；本目录里的种子保持只读。
- 主人目录与种子同名版本冲突时，主人目录优先（例如主人目录已有 `v1.md`，种子 `v1.md` 不会被采用）。

## 解析与注入

- 读取侧（`src/runtime/persona.mjs`）合并两处版本、取最大数字，作为 `memsys:persona` 段注入。
- 该段固定排在记忆段之前：`memsys:persona` order=400 < `memsys:context` order=500。
- 注入长度上限 `PERSONA_MAX_CHARS`（默认 3000 字），超长时截断并标注完整版本号。

## 谁能改

- 只有主人的设置页（loopback + 同源）或 CLI 迁移/维护通道能写；判据是 `src/write/authority.mjs` 的 `assertOwnerRuntime`。
- 模型工具与跨插件 service 接口不暴露人格写入口。
